# IBTrACS 字段与清洗规则

依据 [NOAA v04r01 字段说明](https://www.ncei.noaa.gov/sites/default/files/2025-09/IBTrACS_v04r01_column_documentation.pdf) 和实际 CSV 表头解析。未知或缺失可选字段不会被虚构；必需字段缺失时拒绝导入并记录错误。

## 事件和观测

| 字段 | 含义与处理 |
| --- | --- |
| SID | IBTrACS 系统唯一编号，用于事件分组；不能用名称代替唯一编号 |
| SEASON、NUMBER | 原始年份与序号，保留并供检索 |
| NAME | 原始名称；未命名系统保留来源值 |
| ISO_TIME | 解析为 UTC；API 使用带 `Z` 的 ISO 8601 时间；图表明确标注 UTC |
| BASIN、SUBBASIN | 海域与子海域；本阶段只导入 BASIN=WP 记录 |
| LAT、LON | IBTrACS 合成中心位置，验证纬度 [-90,90]、经度 [-180,180] |
| CMA_LAT、CMA_LON | 机构原始位置单独保存；不会静默覆盖合成位置 |
| NATURE | 原始气旋性质代码，不将所有记录自动解释为台风强度等级 |
| TRACK_TYPE | 主轨迹、分支轨迹或暂定轨迹；保留原类型并可在详情筛选 |
| IFLAG | 保留官方机构原始/插值标记，以便后续样本选择 |
| source_file_id | 对应已登记的原始源文件 |
| quality_flags | 缺测、特殊编码、异常数值等质量标记数组 |
| raw_values | 原始 CSV 行的字段和值，用于回查和后续规范化 |

## 风速口径

CSV 单位行用于核验字段单位；通常风速为 `kts`、气压为 `mb`，气压的 mb 与 hPa 数值相同。单位行不会作为业务记录入库。

| 原始字段 | 平均时段 | 规范化字段 | 说明 |
| --- | --- | --- | --- |
| CMA_WIND | 2 分钟 | cma_wind_ms | 默认分析口径，无其他机构静默补值 |
| USA_WIND | 1 分钟 | usa_wind_ms | 单独展示，具体美国来源保留于原始字段 |
| TOKYO_WIND | 10 分钟 | tokyo_wind_ms | JMA 机构口径 |
| WMO_WIND | 取决于 WMO_AGENCY | wmo_wind_ms | 同时显示责任机构；不能自动标注成固定 2 分钟 |

只进行物理单位转换：`m/s = knots × 0.514444`。该转换不改变风速平均时段，不把 1 分钟或 10 分钟风速换算成 CMA 的 2 分钟风速。

**CMA_WIND=17 knots 是特殊低风速代码。** NOAA 说明其原始 CMA 9 m/s 表示最大持续风速小于 10 m/s。因此系统保留原始 17，但规范化 `cma_wind_ms` 为空并添加特殊编码标记，不将它作为 8.745548 m/s 的精确测量值计算极值或曲线。

空字符串、纯空格及缺测标记保持缺失；负风速、非正气压等异常值在规范化结果中为空并保留原始字段与质量标记。缺测点不进行软件插值，图表不会穿越缺口连接出虚假观测。

## CMA 强度分类

`CMA_CAT` 为中国气象局原始分类：0 为弱于热带低压或强度未知，1 为热带低压，2 为热带风暴，3 为强热带风暴，4 为台风，5 为强台风，6 为超强台风，9 为温带气旋阶段。等级筛选依据真实原始分类或已记录事件最大分类，不能将美国风速自动当作 CMA 等级。

## 时间、重复与版本

不假设全部观测为 6 小时间隔。IBTrACS 包含 3 小时插值点及其他时次，原始时间排序后保存。后续训练需进一步依据 IFLAG、实际时差和机构字段选择输入样本。

相同文件 SHA-256 再次导入不增加业务数据。相同事件、时间、轨迹类型的重复行按内容识别；不同内容的冲突记录保留其原始信息并计入导入统计。不同轨迹类型不相互覆盖。界面默认主轨迹，其他类型仍可查询。

事件汇总风速和气压仅采用 MAIN 轨迹 CMA 字段；同一时刻的冲突版本默认选择最后入库的记录，和地图、曲线一致。全部冲突原始版本仍可通过分页观测接口查询。无 MAIN 的事件保留全轨迹起止时间，MAIN 极值为空；可勾选“包含临时轨迹和支轨事件”查看这些档案。2025 年许多记录仍为 US-PROVISIONAL，MAIN 事件数不能解释为当年全部台风数。跨机构切换仅影响独立曲线展示。

# SAF-Net 算法烟雾测试

测试日期：2026-10-26。测试数据为隔离目录中的确定性合成张量，仅验证算法可运行性，不写入正式数据库、模型目录或实验记录，不属于真实台风预测实验。

- 输入：空间 `(2,4,2,31,31)`，时间 `(2,4,1)`。
- 输出：`(2,1)`，全部有限。
- 空间注意力：`(2,4,1,31,31)`，值位于 0—1。
- 时间注意力：`(2,1,8,4,4)`。
- backward：所有可训练参数梯度存在且有限。
- Adam 单步：参数实际更新。
- 保存加载：只保存 state_dict 和纯配置，`weights_only=True` 重新加载后重复推理逐元素一致。
- Batch Size：1、2、5 均通过。
- 非法头数、错误空间/时间形状、NaN、损坏样本和错误目标时间均被拒绝。

默认模型实际参数总量和可训练参数均为 134,468。测试不能用于报告 MAE、RMSE 或模型优越性。

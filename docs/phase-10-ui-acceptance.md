# 第十阶段界面验收方案

验收浏览器为 Microsoft Edge，桌面分辨率覆盖 1440×900，另检查窄屏布局。验收范围：

1. 预测页选择测试样本并完成 6–24 小时真实推理；显示 P10/P50/P90 区间、历史真实值、绝对误差并导出 CSV/PNG。
2. 评估页切换 6、12、18、24 小时；检查 MAE/RMSE/Bias、覆盖率、宽度、Pinball Loss和六组消融。
3. 实验页按模型、类别和数据版本筛选；检查随机种子、Epoch、参数记录、校验和及正式实验保护。
4. 报告中心生成五类第十阶段报告，预览 HTML 并下载 PDF。
5. 全流程记录页面错误、控制台错误和 HTTP 5xx，目标均为 0。

截图文件和最终结论见 `phase-10-screenshot-index.md`，自动化与人工检查结果见 `phase-10-acceptance.md`。

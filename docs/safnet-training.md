# SAF-Net 训练与模型管理

正式训练只读取第四阶段 `spatiotemporal_samples` 和其 `.npz` 文件。每条记录必须满足四个风场来源、`(4,2,31,31)`、四时次时间特征、有限数值、目标为起报后 6 小时及可追溯文件存在；系统从不自动补随机风场。

训练、验证、测试继续使用 2014—2021、2022—2023、2024 分区并检查 SID 无交叉。U/V、时间特征和目标的均值与标准差仅由训练集拟合；验证和测试只应用这些参数。

默认 Adam、学习率 0.001、Batch 16、最多 50 Epoch、耐心 8、梯度裁剪 1.0。后台任务复用实验表，记录真实每轮 MSE、设备、进度、取消、异常、配置和分组统计。测试集只在最佳验证权重确定后评价。

权重保存为 PyTorch `state_dict`，同时保存模型配置、标准化参数和格式版本；JSON 元数据保存数据版本、参数量、训练环境信息及权重 SHA-256。重新加载先校验 SHA-256，再以 `torch.load(..., weights_only=True)` 加载并严格匹配键和形状。

当训练/验证/测试任一真实时空分区为空时，API 在创建实验之前返回业务错误，既不新增实验，也不创建目录、权重、曲线或指标。当前正式 SAF-Net 实验数为 0。

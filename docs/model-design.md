# 模型设计

- **Persistence**：直接使用起报时刻风速作为 t+6h 预测，是所有模型的最低基准。
- **Ridge**：输入四个历史风速及 6h/12h 变化量。标准化只拟合训练集，正则系数只通过验证集 MAE 选择。
- **LSTM/GRU**：输入形状为 `[batch, 4, 1]`。当前主实验使用 16 维隐状态、1 层循环网络和轻量回归头，避免在有限事件上过度复杂。

深度模型使用 AdamW、验证损失早停、梯度裁剪、固定随机种子。CPU 默认限制为 2 个 PyTorch 线程；CUDA 可用时自动选择。训练、早停和超参不读取测试集。

本阶段只有风速主基线。中心气压存在较多缺测，未为了加特征而大量删除样本。未接入 ERA5，未实现 SAF-Net。

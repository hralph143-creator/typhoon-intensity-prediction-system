# 第十阶段 SAF-Net 消融实验

所有消融共享 `multi-horizon-v1-712888310e999cf3`、事件级分区、Pinball Loss、四时效输出和三个预先固定随机种子。每个结构先按验证集 MAE 选择种子，再仅评价一次测试集。

| 结构 | 选择种子 | 验证 MAE | 测试 MAE |
|---|---:|---:|---:|
| history_only | 42 | 1.8020 | 7.6287 |
| spatial_only | 42 | 2.1218 | 13.2111 |
| cnn_average | 42 | 1.7603 | 6.9248 |
| cnn_temporal_attention | 3407 | 1.8445 | 5.1311 |
| spatial_attention_simple | 42 | 1.8778 | 5.6076 |
| full_safnet | 42 | 1.7220 | 6.3721 |

完整结构验证表现最好，但所有结构在测试集均出现明显退化。空间分支单独使用最弱，说明仅凭当前局地 U10/V10 场不足以稳定刻画未来强度。结果属于负面但可复现实验，不进行事后删样本或重选随机种子。

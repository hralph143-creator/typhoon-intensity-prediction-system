# 第九阶段功能总览

## 交付范围

第九阶段在不重新训练模型、不下载新气象数据的前提下，对现有科研系统进行交付级完善。软件版本更新为 0.9.0，正式名称保持“基于时空注意力的台风强度预测系统”，品牌名称为“云浪智析”。

## 完整业务链路

1. 首页读取 IBTrACS、CMA、ERA5、模型、实验和报告的真实统计，提供历史查询、风场、预测、评估和报告快捷入口。
2. 历史台风支持来源切换、组合筛选、详情地图、强度曲线、原始观测和数据来源追溯。
3. ERA5 风场支持选择 90 个真实四时次样本，在合成风速、U10、V10及四时次对比、单时次视图之间切换。
4. 模型管理覆盖 Persistence、Ridge、LSTM、GRU、SAF-Net，展示权重文件是否存在及 SHA-256 是否匹配；成功实验受到界面保护。
5. 强度预测调用已保存的真实模型权重，展示四时次输入、未来 6 小时预测、历史真实值、误差、空间注意力和多头时间注意力，并支持 CSV/PNG 导出。
6. 模型评估仅在冻结共同测试集内进行正式横向比较，同时保留数据版本、事件数、预测时效和 Bootstrap 不确定性说明。
7. 科研报告支持类型和状态筛选、HTML 预览、HTML/PDF 下载；相同科研快照会复用已有报告，机器负载导致的推理耗时不参与快照指纹。
8. 系统设置支持日志筛选与下载、SQLite 一致性备份、完整性校验、备份下载、受控恢复和临时文件清理。
9. Windows 启动器支持 `run.bat`、`run.bat --check` 和 `run.bat --stop`。退出只关闭当前项目的前后端进程树。

## 新增接口

- `GET /api/era5/samples`：按 SID、分区和数量获取真实时空样本元数据。
- `GET /api/era5/samples/{sample_id}`：读取真实 NPZ 样本的 U10/V10、中心、时次、范围及质量信息。
- `GET /api/system/backups/{backup_id}/download`：完整性校验通过后下载 SQLite 备份。
- 模型和实验接口补充模型文件名、元数据文件名、文件存在状态和校验结果，不向界面暴露绝对路径。

## 科研边界

当前冻结集共 90 个真实 ERA5 四时次样本、32 个独立事件，训练/验证/测试为 50/20/20 条。共同测试集为 20 条样本、6 个独立事件。SAF-Net 测试 MAE 为 4.0427 m/s，高于 Persistence 的 1.9034 m/s；系统不把该结果描述为性能优势，也不将历史回测表述为实时业务预报。

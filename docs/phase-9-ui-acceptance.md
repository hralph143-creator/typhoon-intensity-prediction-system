# 第九阶段界面验收

## 统一规范

- 采用深蓝侧边导航、白色内容卡片和低饱和蓝灰信息层级，统一卡片、按钮、输入框、表格和弹窗圆角。
- 页面内容最大宽度为 1680 px，侧边栏和顶部栏保持固定可达；1600×900 与 1366×768 均无页面级横向溢出。
- 删除开发阶段、等待后续和生成式占位语气；保留数据口径、质量边界和非业务预报等必要科研说明。
- 首页及设置页不展示本机绝对路径；模型详情仅展示文件名和校验状态。
- 所有空状态、失败状态、禁用状态和高风险操作均有明确反馈；恢复、删除、清理继续要求二次确认。

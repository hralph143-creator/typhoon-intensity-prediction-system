# 第六阶段验收记录

验收范围包括三类真实报告、独立 HTML/PDF、正式模型公平比较、预测记录筛选、XLSX/CSV/PNG 导出，以及运行状态、日志、一致性备份和临时文件维护。后端自动测试使用隔离数据库；正式数据库仅用于只读报告生成和手动备份校验，未执行恢复。

PDF 验收要求逐页渲染为 PNG，检查中文、分页、表格和图表不裁切，并用 PDF 解析器确认文件结构。浏览器验收使用本机 Edge 检查报告创建、轮询、预览、下载和系统设置页面。

2026-10-26 实际验收：生成 MERANTI 历史分析、LSTM 正式评估和综合科研分析共 3 份报告、9 个 PDF 页面；正式库包含 366 个事件和 23,188 条观测，四个历史模型测试样本均为 722，LSTM MAE 为 1.6075 m/s。创建 116,506,624 字节的一致性备份并通过校验，未在正式数据库执行恢复。pytest 92 项、Vitest 20 项、TypeScript 检查和生产构建通过；Edge 验收 3 个页面且无脚本错误。

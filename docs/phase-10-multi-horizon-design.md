# 第十阶段多时效设计

模型输入为四个历史时次，输出张量显式固定为 `(batch, 4 horizons, 3 quantiles)`，时效顺序为 6、12、18、24 小时，分位数为 P10、P50、P90。缺失目标通过布尔掩码从损失和指标中排除。

系统实现了逐时效传统基线（Persistence、Ridge）和共享四时效输出的 GRU、SAF-Net 候选。当前真实数据规模下，共享输出方案可减少模型文件并显式利用时效关系；独立模型方案保留为验证比较方向，但不使用测试集决定方案。

测试总体 MAE：Persistence 4.4564、Ridge 5.9115、GRU 7.2001、候选 SAF-Net 6.3721 m/s。候选分时效 MAE 为 5.3112、5.9090、7.3064、6.9619 m/s。Persistence 仍是当前多时效最强基线。

API 提供审计、实验摘要、样本列表、单样本真实推理和 CSV 导出。每次推理返回数据版本、模型 ID、结构、随机种子及历史回测标记。

## 轨迹、IFLAG 和间隔

- 轨迹：MAIN 21,246；US-PROVISIONAL 1,894；US-PROVISIONAL_SPUR 25；SPUR-MERGE 18；PROVISIONAL 5。
- CMA IFLAG 第三位：O 10,513；P 9,039；缺失 3,636；未出现 I/V。
- 相邻 MAIN 观测间隔：1h 255；2h 60；3h 20,599；15h 1。窗口使用精确 UTC 匹配，因此中间存在 3h 记录不会导致跨行误判。
- 331 个 MAIN 事件的序列长度为 2—172 条。逐 SID 长度和完整分布保存在审计 API 的 `event_sequence_lengths` 和 `sequence_length_distribution`。

## 缺测、特殊编码和窗口

- 全部观测 23,188；CMA 风速有效 19,552；缺失 3,636，占 15.6805%。
- CMA 17 kn 特殊低风速编码 0；范围外风速 0。处理逻辑仍明确将 17 kn 排除出精确标签。
- 严格配置有 8,420 个完整历史输入窗口，其中 8,048 个存在可靠 t+6h 标签。
- 扩展配置有 15,776 个完整历史输入窗口，其中 15,136 个存在可用 t+6h 标签。

严格主实验不将 P 插值强度混入独立评价。US-PROVISIONAL 是否可用逐字段审计，不做整个轨迹的粗暴判定。

# SAF-Net 网络结构与输入输出

SAF-Net 是双分支风速回归网络，预测目标为起报后 6 小时 CMA 最大持续风速（m/s），不是分类模型。

## 输入输出

- 空间输入：`(B,4,2,31,31)`，顺序为 `t-18h、t-12h、t-6h、t`，通道为 U10/V10。
- 时间输入：`(B,4,F)`。当前 `F=1`，每时次只含当时 CMA 风速。96 是隐藏嵌入维度，不代表 96 个原始指标。
- 输出：`(B,1)`，对应 `t+6h` 风速。

## 空间分支

四个时次共享 `Conv2d(2,32) → BN → ReLU → Conv2d(32,64) → BN → ReLU`。每时次用通道平均和最大值形成两通道描述，经 7×7 卷积和 Sigmoid 得到真正的 `31×31` 空间注意力，再加权 CNN 特征并自适应池化。四时次保持独立和有序，不会先平均成一张图。

## 时间分支

`Linear(F,96)` 后加入可学习的四位置编码。默认 1 层、8 头自注意力，每层包含预归一化、残差、两层 GELU 前馈网络与 Dropout。接口保留每层每头 `4×4` 注意力矩阵。嵌入维度不能被头数整除时，初始化立即失败。

## 融合与参数量

空间序列投影为 96 维，并以可学习的时间权重聚合；时间分支取起报时刻上下文。两者拼接后经过 `Linear → LayerNorm → GELU → Dropout → 回归头`。

默认实际参数：134,468，全部可训练。其中空间编码器 19,298，时间编码器 75,552，融合与预测头 39,618。数值由运行时代码计算，不是固定展示值。

# 科研分析报告

“科研分析报告”支持历史台风、模型评估和综合科研分析三类报告。创建任务时系统先形成不可变数据库快照及 SHA-256 标识，再由单工作线程绘图并生成独立 HTML 与 A4 PDF；相同快照默认复用，勾选重新生成才创建新记录。

台风报告采用 MAIN 历史轨迹及 CMA 2 分钟平均风速；模型报告只读取已成功实验及其已保存测试点；综合报告汇总实际事件、观测、ERA5 文件、时空样本和正式实验。缺失字段直接说明，不填补或推测。SAF-Net 没有正式真实结果时明确排除在排名外。

每份报告保存来源说明、生成时间、报告编号、配置和快照哈希。预览无需联网；PDF 带页码、图表编号、表格标题及科研用途边界。

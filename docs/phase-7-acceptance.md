# 第七阶段实际验收报告

验收日期：2026-10-28。实验定位为历史再分析条件下的小样本回测，不代表实时业务预报。

## 数据融合与质量审计

- 原有数据完整保留：IBTrACS 366 个事件、23,188 条观测；独立 CMA 342 个事件、10,791 条观测；第三阶段严格样本仍为 8,048 条。
- 事件关联算法 `event-match-v1` 使用同年、生命周期重叠、同 UTC 轨迹距离和名称辅助信息。名称不能单独定案。
- 实际结果：确认匹配 308 对，候选 2 对，冲突 0 对；IBTrACS 未匹配 58 个，CMA 未匹配 34 个。
- 匹配记录保留双方原始 SID、依据、置信度、冲突状态和算法版本，可重新计算。

## ERA5 扩充

- 数据源：ECMWF/Copernicus ERA5，由 Google Cloud 公共 ARCO-ERA5 托管。
- 新增受预算约束的批次任务：单并发、磁盘预算检查、估算、取消、错误保留、缓存复用和幂等构建。
- 本轮批次请求 6 条，成功 6 条，失败 0 条，实际新增归档 361,536 字节。
- 当前总计：ERA5 文件 7 个，单时次风场 25 个，四时次样本 7 个，本地原始归档 413,568 字节。
- 分组：训练 3 条/2 个事件，验证 2 条/2 个事件，测试 2 条/2 个事件；SID 无跨集合交叉。
- 每条样本形状为 `(4,2,31,31)`，时间为 t-18h、t-12h、t-6h、t，标签为 t+6h，输入不含未来信息。
